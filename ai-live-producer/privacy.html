AI Live Producer 개인정보 처리방침

시행일: 2026년 11월 3일 · 운영: AICOMPANY

한국어English

AI Live Producer(이하 “프로그램”)는 틱톡 LIVE 크리에이터와 에이전시가 자기 방송을 기록·분석하도록 돕는 Windows PC용 프로그램입니다. 이 방침은 프로그램이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 핵심 요약

  • 프로그램이 다루는 정보는 사용자 PC 안에만 저장됩니다. 운영사는 별도 서버를 운영하지 않으며, 사용자의 정보를 받거나 보관하지 않습니다.
  • 틱톡 계정 정보는 크리에이터가 틱톡 로그인 화면에서 직접 허락한 범위만 가져옵니다.
  • 정보를 판매하거나 광고에 쓰지 않습니다.

2. 다루는 정보

가. 틱톡 공식 연결(TikTok Login Kit · Display API)로 받는 정보

크리에이터가 프로그램의 “틱톡으로 로그인”을 눌러 허락한 경우에만, 본인 계정의 다음 정보를 받습니다.

권한 범위(scope)받는 정보쓰는 곳
user.info.basicopen_id, union_id, 표시 이름, 프로필 사진 주소어느 계정이 연결됐는지 보여 주고, 다른 계정의 기록이 섞이지 않게 확인
user.info.profile아이디(username), 인증 배지 여부, 소개글연결된 계정이 이 크리에이터 기록의 주인인지 확인
user.info.stats팔로워·팔로잉·받은 좋아요·영상 수방송 전후 팔로워 변화 등 성장 지표 기록
video.list최근 영상의 제목·올린 날짜·조회·좋아요·댓글·공유 수영상 성과를 방송 기록과 함께 보여 줌

로그인 토큰(access token·refresh token)은 사용자 PC의 크리에이터 기록 파일에만 저장되고, 로그아웃하면 지워집니다.

나. 방송 화면에서 읽는 정보

사용자가 켠 경우, 프로그램은 사용자 PC 화면에 보이는 틱톡 LIVE 채팅 영역을 글자 인식(OCR)으로 읽어 채팅·선물·입장 알림 같은 방송에 공개적으로 표시된 내용(시청자 닉네임과 메시지 포함)을 기록합니다. 글자 인식은 PC 안에서만 처리됩니다.

다. 사용자가 직접 넣는 정보

LIVE Backstage·TikTok Studio·LIVE Center에서 사용자가 내려받아 프로그램에 넣은 CSV·엑셀 파일의 내용, 그리고 사용자가 입력한 틱톡 개발자 앱 키는 PC 안에만 저장됩니다.

3. 외부로 보내는 경우

아래는 사용자가 해당 기능을 직접 켰을 때만 일어납니다.

  • TikTok: 공식 연결 시 로그인·정보 요청을 틱톡 서버(open.tiktokapis.com)로 보냅니다.
  • 웹으로 보기: 사용자가 켜면 Cloudflare의 임시 주소(trycloudflare.com)를 통해, 그 주소를 받은 사람이 방송 현황 화면을 볼 수 있습니다. 끄면 주소가 사라집니다.
  • 음성 받아쓰기(선택): 사용자가 OpenAI 또는 ElevenLabs를 고르고 본인 API 키를 넣은 경우, 마이크 음성이 해당 회사로 보내져 글자로 바뀝니다. 기본값은 PC 안에서 처리하는 방식입니다.

그 밖에 글자 인식 모델 파일을 내려받는 등 개인정보가 포함되지 않은 통신만 있습니다.

4. 보관 기간과 삭제

  • 기록은 사용자가 지울 때까지 사용자 PC의 프로그램 data 폴더에 남습니다. 폴더나 해당 크리에이터 기록 파일을 지우면 모두 삭제됩니다.
  • 틱톡 연결은 프로그램의 “로그아웃”으로 끊을 수 있고, 틱톡 앱의 설정 및 개인정보 › 보안 및 권한 › 앱 및 서비스 권한에서도 언제든 권한을 취소할 수 있습니다.

5. 이용 대상

프로그램은 틱톡 LIVE를 진행하는 성인 크리에이터와 그 소속 에이전시를 위한 업무용 도구이며, 만 18세 미만을 대상으로 하지 않습니다.

6. 안전 조치

정보는 사용자 PC 안에만 저장되므로, PC 계정 암호와 백신 등 일반적인 PC 보안을 유지해 주세요. 틱톡 로그인은 틱톡의 공식 OAuth(PKCE) 방식을 쓰며, 프로그램은 틱톡 비밀번호를 받지 않습니다.

7. 변경

방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다.

8. 문의

운영: AICOMPANY (대한민국). 문의는 프로그램을 제공받은 에이전시 또는 운영사로 해 주세요.

AI Live Producer Privacy Policy

Effective: November 3, 2026 · Operated by AICOMPANY

AI Live Producer (the “App”) is a Windows desktop application that helps TikTok LIVE creators and their agencies record and analyze their own broadcasts. This policy explains what information the App handles and how.

1. Summary

  • All information the App handles is stored only on the user’s own PC. The operator runs no server and does not receive or keep user data.
  • TikTok account data is obtained only within the scopes the creator explicitly authorizes on TikTok’s login screen.
  • We do not sell data or use it for advertising.

2. Information the App handles

a. Data from TikTok Login Kit and Display API

Only after the creator clicks “Log in with TikTok” and authorizes the App, the App receives the following about the creator’s own account:

ScopeDataPurpose
user.info.basicopen_id, union_id, display name, avatar URLShow which account is connected and make sure records of different accounts are never mixed
user.info.profileusername, verified status, bioConfirm the connected account owns the creator record it is saved to
user.info.statsfollower, following, likes and video countsTrack growth, e.g. follower change before and after a LIVE
video.listrecent videos’ title, post date, view, like, comment and share countsShow video performance next to broadcast records

Access and refresh tokens are stored only in the creator’s record file on the user’s PC and are deleted on logout.

b. Information read from the broadcast screen

If the user turns it on, the App reads the TikTok LIVE chat area shown on the user’s own screen with on-device text recognition (OCR) and records what is publicly displayed in the broadcast (chat messages, gifts and join notices, including viewer nicknames). Recognition runs entirely on the PC.

c. Information the user provides

CSV/Excel files the user exports from LIVE Backstage, TikTok Studio or LIVE Center and imports into the App, and the TikTok developer app keys the user enters, are stored only on the PC.

3. When data leaves the PC

Only when the user turns on the related feature:

  • TikTok: login and data requests are sent to TikTok (open.tiktokapis.com).
  • Web view: a temporary Cloudflare link (trycloudflare.com) lets people who receive the link view the live dashboard. Turning it off removes the link.
  • Speech-to-text (optional): if the user selects OpenAI or ElevenLabs and enters their own API key, microphone audio is sent to that provider for transcription. The default runs on the PC.

Other network traffic, such as downloading text-recognition model files, contains no personal data.

4. Retention and deletion

  • Records stay in the App’s data folder on the user’s PC until the user deletes them. Deleting the folder or a creator’s record file removes everything.
  • The TikTok connection can be ended with “Log out” in the App, and access can be revoked at any time in the TikTok app under Settings and privacy › Security and permissions › Apps and services permissions.

5. Who the App is for

The App is a business tool for adult TikTok LIVE creators and their agencies and is not directed to anyone under 18.

6. Security

Because data is stored only on the user’s PC, please keep the PC protected with an account password and anti-virus software. TikTok login uses TikTok’s official OAuth (PKCE) flow; the App never receives TikTok passwords.

Changes will be posted on this page with a new effective date.
